센서·영상 데이터 기반 품질 예측 모델 개발

센서와 영상 데이터로 대상의 상태를 정량적으로 예측하는 모델을 만듭니다. RGB·초분광·뎁스 등 서로 다른 성질의 데이터를 다루며, 데이터 수집 설계부터 전처리, 모델 학습, 성능 검증까지 분석 파이프라인 전 과정을 수행해 왔습니다.

여러 모델을 비교해 근거를 갖고 하나를 선택하는 일, 그리고 그 선택이 실제 운영 환경에서 유지되는지 검증하는 일에 강점이 있습니다. 정확도 1위 모델이 항상 정답은 아니라고 생각합니다.

P.01 · 국립순천대학교 · 석사 학위논문 · 2024

실시간 객체 탐지 모델 비교·선정 및 로봇 시스템 적용

좁은 간격으로 혼재된 두 대상을 로봇이 실시간으로 구분해야 하는 문제에서, 객체 탐지 모델 5종(YOLOv8, YOLOv11, RT-DETR, EfficientDet, Faster R-CNN)을 직접 수집·라벨링한 이미지 234장으로 학습해 정확도와 추론 속도를 함께 비교했다. 대상 A는 YOLOv11(F1 0.943, mAP@0.5 0.970), 대상 B는 RT-DETR(F1 0.803, mAP@0.5 0.889)이 가장 우수했고, 추론 속도(RT-DETR 대비 1.86배)를 함께 고려해 YOLOv11을 탑재 모델로 최종 선정, 레이저 제거 로봇 시스템에 적용했다. 2024.01 – 2024.12.

Object Detection Model Benchmarking Embedded Deployment

P.02 · 서울대학교 생체물성연구실 · 2025

항공 RGB 영상 시맨틱 분할 및 학습 전략 최적화

항공 촬영한 RGB 영상에서 4종 대상을 픽셀 단위로 구분해야 하는 과제에서, 단일 통합 모델의 한계를 확인하고 대상군을 분리해 학습하는 전략을 설계했다. Mask2Former 기반 분할 모델에 분리 학습 전략을 도입한 결과 mIoU가 57.25%에서 최대 77.33%(+20%p)로 개선되었다. 전국 3개년(2022–2024) 데이터를 시간적으로 분리해 평가 설계를 구성하고 촬영 고도(10–100m)별 일반화 성능을 검증한 결과, 저고도(10–30m) 학습이 가장 우수한 일반화 성능을 보였다. 2025.03 – 2025.07.

Semantic Segmentation Mask2Former Temporal Split Validation

P.03 · 서울대학교 생체물성연구실 · 2025

초분광 영상 기반 비파괴 함수율 예측 회귀 모델

대상을 파괴하지 않고 내부 수분 상태를 정량 예측해야 하는 과제에서, Vis-NIR(400–1000nm)·NIR(900–1700nm) 초분광 카메라 2종으로 데이터 수집 시스템을 구축하고 전처리 기법(SNV, MSC, SG, 1·2차 미분)을 비교해 최적 파이프라인을 도출했다. PLSR·ANN 회귀 모델을 R²·RMSE 기준으로 비교 평가했고, SAM2 기반 반자동 스펙트럼 세그멘테이션으로 라벨링 정확도 95% 이상을 확보해 라벨링 공정을 단축했다. 2025.09 – 2025.12.

Hyperspectral Imaging PLSR / ANN SAM2

초분광 영상 기반 복합재 물성 분류·예측 모델

팀 단위로 수행한 프로젝트로, 초분광 영상 기반 복합재의 물성 분류·예측 모델 개발에 데이터 수집과 모델 개발 파트로 참여했다. 4종 센서(Vis-NIR·NIR 포함)로 수집한 데이터에 전처리 및 특징 추출 기법을 적용했다. 2025.07 – 2025.09 · Team project.
