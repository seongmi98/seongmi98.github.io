Home Portfolio 객체 탐지 모델 비교·선정

실시간 객체 탐지 모델 비교·선정 및 로봇 시스템 적용

  • 기간: 2024.01–2024.12
  • 소속: 국립순천대학교 · 석사 학위논문
문제
좁은 간격으로 혼재된 두 대상을 로봇이 실시간으로 구분해야 함
접근
직접 수집·라벨링한 이미지 234장으로 객체 탐지 모델 5종(YOLOv8, YOLOv11, RT-DETR, EfficientDet, Faster R-CNN) 학습·비교
결과
대상 A는 YOLOv11(F1 0.943, mAP@0.5 0.970), 대상 B는 RT-DETR(F1 0.803, mAP@0.5 0.889) 최우수. 추론 속도(RT-DETR 대비 1.86×)를 함께 고려해 YOLOv11을 탑재 모델로 최종 선정, 레이저 제거 로봇 시스템에 적용
