초분광 영상 기반 비파괴 함수율 예측 회귀 모델

  • 기간: 2025.09–2025.12
  • 소속: 서울대학교 생체물성연구실
문제
대상을 파괴하지 않고 내부 수분 상태를 정량 예측해야 함
접근
Vis-NIR·NIR 초분광 카메라 2종으로 데이터 수집 시스템 구축, 전처리 기법(SNV, MSC, SG, 1·2차 미분) 비교로 최적 파이프라인 도출, PLSR·ANN 회귀 모델을 R²·RMSE 기준 비교 평가
결과
SAM2 기반 반자동 스펙트럼 세그멘테이션으로 라벨링 정확도 95% 이상 확보, 라벨링 공정 단축
