Home Portfolio 타슈 대여 데이터 분석

대전 공공자전거 '타슈' 대여 데이터 분석 및 이상치 검증

  • 구분: 석사 과정 수업 기말 과제 (통신용집적회로)
  • 데이터: 대여이력 2022.08~2022.12 · 약 132만 건 + 기상청 기온·강수량
  • 사용 기술: Python, Pandas, Matplotlib, Seaborn
개요

타슈 대여이력 약 132만 건에 기상 데이터를 결합해 요일·시간대 패턴, 날씨 영향, 인기 대여소와 경로를 분석함. 이후 재점검에서 인기 대여소 1위가 실제 대여소가 아닌 정비 거점의 운영 로그(전체의 5.1%)임을 발견해, 이를 제외하고 다시 분석함.

개요 데이터 결과 후속 검증 결론
문제 정의

배경

석사 과정 수업(통신용집적회로) 기말 과제로 수행한 정형 데이터 분석임. 대전시 공영자전거 '타슈'의 대여이력에 기상 데이터를 결합해 언제, 어디서, 어떤 날씨에 이용이 몰리는지를 수치로 확인하는 것이 목표였음.

기상기상청 일별 기온, 강수량
결과

① 요일·시간대 패턴

요일과 시간대별 대여건수를 히트맵으로 정리함. 평일은 출퇴근 시간대(7~9시, 17~20시)에, 주말은 오후(13~22시)에 대여가 집중됨. 평일과 주말의 수요 구조가 다르다는 점을 근거로 시간대별 스테이션 배치 최적화를 제안함.

강수량−0.32

관측 기간(8~12월) 안에서는 기온보다 강수량의 영향이 뚜렷했음. 비 오는 날 이용이 줄어든다는 것을 수치로 확인함.

결과

③ 인기 대여소와 경로

대여·반납 대여소와 이동 경로 상위 10곳을 집계해, 한밭수목원, 카이스트 캠퍼스처럼 공원과 학교 주변에 이용이 몰린다는 것을 확인함.

후속 검증

운영 로그가 섞인 데이터

과제 이후 분석을 다시 열어 점검하던 중, 인기 대여소 1위로 '타슈관제센터'가 나온 것이 이상해 원본을 다시 확인함. 이곳은 일반 대여소가 아니라 자전거를 회수해 정비하는 운영 거점(정비입고/정비대기)이었음.

구분평균 이용시간평균 이동거리건수
관제센터(정비)96.7분7.07km67,440건 (5.1%)
일반 이용자22.6분3.44km1,114,441건

관제센터 관련 건은 평균 이용시간이 일반 이용자의 4배 이상이라, 실제 탑승이 아니라 회수 과정에서 찍힌 운영 로그로 판단함. 이를 제외하고 다시 집계하자 한밭수목원, 무역전시관입구, 유성구청, 타임월드, 충남대학교 학생회관 순으로 실제 이용 패턴이 드러남.

결론

정리

공공데이터에는 이용자 기록과 운영 기록이 섞여 있을 수 있고, 이를 걸러내지 않으면 순위 같은 단순 집계부터 왜곡됨. 결과가 그럴듯해 보여도 원본 단위로 다시 확인한다는 원칙을 정형 데이터에서도 확인한 과제임.
